# Інтеграція залишкових функцій maks37614/social у h00k Community

Аудит джерела: `maks37614/social`, `src/components/TraderProfileView.tsx`,
`LeftTraderSidebar.tsx`, `PostCard.tsx`, `PostComposerModal.tsx`,
`ChatMessengerPanel.tsx`, `ArticlesView.tsx`.
Ціль: `maks37614/h00k-community`, зокрема `/u/maks` на staging.

## Реалізовано на живих даних Community

| Джерело social | Реалізація Community |
| --- | --- |
| Банер, квадратний аватар | `publicProfile.tsx`, `publicProfileSocialSourceClone.css`, власний редактор аватара/обкладинки |
| Редагування опису, вибір статусу в лівій колонці | `CommunityConceptProfile.tsx`; автентифікований `/api/account/profile` PATCH без уявних станів |
| Публічні коментарі з фото автора | Власний route `/api/public/profiles/:username/posts/:id/comments/:comment/avatar`, тільки для дозволених відкритих коментарів, авторів із опублікованим профілем та власних публічних медіа |
| Публікації, реакції, відповіді, фото, закладки | Реальні `CommunityPage`, `server/community/routes.ts`, з правилами аудиторії |
| Статті та практичні розбори | `PublicProfileArticles`, справжні відкриті освітні публікації |
| Подарунки, репутація, досягнення | `CommunityAwardPanel`, серверні записи про вручення, дозволені відкриті суми/кількості |
| Торгові сесії, часові пояси | `CommunityTradingSessions`, часові зони з підтримкою переходів часу |
| Друзі, приватні/групові чати | Справжні серверні розмови із правами доступу; немає публічних номерів, телефонів чи повідомлень |
| Кількість друзів у public hero | Підтверджені, не заблоковані дружні зв'язки зі сховища; лише після прапорця `publicFriendsCountEnabled=true`. Список/імена друзів публічно не віддаються, підписники не підміняються друзями |
| Прикріплення графіка та рівнів | `HookChart` зі збереженого знімка, без live біржових потоків на публічних картках |
| Торговий профіль, результати | Лише дозволені агрегати закритих ордерів, без підставленої статистики з mockData |

## Не копіюємо як реальні твердження

- `mockData.ts`: прибуткові угоди, вигадані Win Rate/PnL/Profit Factor, лічильники підписників, нагороди, активні позиції, країни й онлайн-статуси.
- Демонстраційні кімнати або повідомлення, яких немає в реальній базі; непідтверджені статуси «В угоді», «В мережі» не виводяться як факти.
- Демонстраційні картки ручного PnL зі `PostComposerModal` не позначаються як підтверджені біржею. Перевірені дані можуть мати лише окреме контрольоване джерело.
- Тестові референсні аватари, обкладинки, віддалені stock images і жорстко задані геодані: власник завантажує фото й явно відкриває доступ.

## Подальші можливості, що потребують окремого проєктування

- Повноцінна міжкористувацька стіна з гостьовими записами (з власними правилами приватності, модерацією, блокуванням і сповіщеннями).
- Підписники: треба спочатку визначити окремі дозволи й схему підписок; не слід підміняти ними кількість друзів.
- Картки ручного PnL та «у позиції» лише з чіткою позначкою **не перевірено**, без фальшивих результатів або змішування з імпортованими угодами.

Цей аудит не є заявою, що всі демонстраційні елементи social уже мають серверну реалізацію.
Публічний `/u/` залишається read-only без авторизації, а private/friends дані не потрапляють до гостьових API.

## Розгортання лічильника друзів

Ця зміна потребує запуску штатної команди `npm run community:migrate` із **нового** Docker-образу Community перед його ввімкненням. Міграція лише додає частковий індекс `hc_friendships_accepted_recipient` (для продуктивності), не видаляє наявні записи й не змінює структуру персональних даних. На невеликих тестових базах зміна має бути швидкою; на живій базі перевірте розмір таблиці та відповідний maintenance window.

Завжди зробіть резервну копію PostgreSQL до міграції. Оновлюйте лише сервіс Community, не перезапускаючи основний скрінер `h00k.top`, його контейнери та боти.
