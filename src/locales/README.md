# Мовні файли SignalHook

Усі тексти для редагування мов зібрані в цій папці:

- `uk.ts` — українська
- `en.ts` — English
- `ru.ts` — Русский
- `pl.ts` — Polski

Кожен файл має три основні секції:

- `strings` — основні системні ключі інтерфейсу, які використовуються через `t('key')`.
- `phrases` — повний каталог знайдених підписів, кнопок, підказок, повідомлень, модалок і текстів блоків. Ключ — вихідна фраза, значення — текст цією мовою.
- `telegram` — шаблони повідомлень Telegram. Не видаляйте плейсхолдери виду `{{symbol}}`, `{{price}}`, `{{time}}`, `{{entry}}` тощо: система підставляє в них живі дані.

Щоб змінити переклад, редагуйте тільки значення справа. Наприклад:

```ts
"addChart": "Додати графік"
```

або:

```ts
"Додати графік": "Add chart"
```

Після редагування мовного файла перезапустіть/перебудуйте сайт. Вибрана користувачем мова зберігається під ключем `crypto_screener_language` і використовується також для серверних Telegram-сповіщень.

## HookChart

`hookchart/uk.json`, `hookchart/en.json`, `hookchart/ru.json` і `hookchart/pl.json` містять словники HookChart. Мова графіка синхронізується з мовою сайту; налаштування, індикатори та малюнки зберігаються окремо у профілі користувача.

`index.ts` та `types.ts` — службові файли. Для звичайного редагування перекладів їх змінювати не потрібно.
